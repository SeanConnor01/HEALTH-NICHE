TASK: Create a text-only premium short-form health video package with DIRECT TEXT-TO-VIDEO PROMPTS ONLY. Never produce image/image-to-video prompts or media. Write polished international English for premium markets and adapt to any supplied audience.


STORY AND SCIENCE: Create one suspenseful chronological story, not a benefit list. Use a topic-specific ≤12-word hook, one honest curiosity gap, one cause-and-effect mechanism, an obstacle/processing step, the strongest accurate reveal near the final third, a responsible payoff, and a topic-specific ≤15-word CTA. Never claim miracle, cure, detox, guaranteed sleep/fat loss, disease treatment/prevention, or unsupported outcomes. Distinguish established from emerging evidence.


TIMING AUTHORITY: Use: 1) actual supplied voiceover duration, 2) exact target duration, 3) duration estimated from the finished script. If only target duration is supplied, write at 150–175 WPM, approximately 160 WPM by default: target words = seconds × 160 ÷ 60. Write the script as one paragraph on one physical line. Never use duration ÷ 2.5, 3.1 words per second, fixed 2–3-second scenes, fixed scene counts, or sentence count as scene count.


ATOMIC VISUAL BEAT RULE — NON-NEGOTIABLE: Timing follows beats, never arbitrary clip length. Read the finished script word by word. Start a scene only when the words require a new filmable action, location, perspective, subject/material, state, direction, structure, reveal state, result state, or CTA action. ONE SCENE = ONE LOCATION + ONE STAGE + ONE DOMINANT ACTION. Split a sentence containing multiple events: “bite an apple, swallow it, and it enters the stomach” requires separate bite, swallowing, and stomach-entry scenes. Never combine independent stages to lengthen a clip. Merge phrases only when subject, location, stage, direction, and continuous action all stay identical. A scene may last under one second or several seconds. The script alone determines N; 30 seconds may need 8, 12, 15, 20, or more scenes.


VISUAL SCENE MAP: Before direct-video prompts, output one code box mapping the entire voiceover. Each line must be:
[Prompt N] — “exact consecutive spoken words” (M:SS.sufficient-precision–M:SS.sufficient-precision)
Use the source audio’s available timestamp precision; use tenths only when duration is exact to tenths. Use word-level timing from actual audio when available. Otherwise estimate from word count, punctuation, pauses, technical terms, and emphasis, then scale to the exact target duration. Every script word must appear once, in order: nothing skipped, repeated, or paraphrased. Timestamps must be contiguous: one scene’s end equals the next scene’s start; no gaps or overlaps; the last scene ends at the exact voiceover duration. The map fixes N and is authoritative for all later prompt, text, and sound lines.


SCRIPT-TO-VISUAL LAW: At every moment, CURRENT VOICEOVER WORDS = CURRENT VISUAL LOCATION AND ACTION. Show only the atomic beat currently spoken. Never show a later location, process, material, benefit, or outcome early. Never continue an earlier action after narration changes. Do not invent an unspoken anatomical route. A direct-video prompt must cover exactly one scene-map line and must not transition into another mapped event. Avoid “then” or “next” inside a prompt when it would compress a separate stage.


VISUAL SELECTION: External/routine/CTA → premium real-world shot. Consumption → real food/drink and only necessary human features. Internal → camera inside exact narrated anatomy; no person, silhouette, body outline/overlay, floating organ, or miniature human. Cellular → exact relevant structure. Systemic/body view only when explicitly narrated. Final beat → exact final spoken process or supported CTA context. Never force unrelated anatomy.


STYLE: Use premium photorealistic non-gory realism, recognisable anatomy, organic texture, believable fluid behaviour, macro depth, selective focus, volumetric light, 9:16 framing, and one dominant action. Identify camera location, structure, material, action, direction, cause, and ending state. Reject generic/abstract art, ribbons, swirls, geometric/glass/crystal forms, sci-fi tunnels, decorative particles/networks, and glowing humans. Rewrite any visual reusable for an unrelated topic. Food appears intact only externally; internally show the appropriate narrated material state.


FUNCTIONAL COLOUR: Amber = digestive fluid; crimson = circulation; gold = narrated nutrients/fats/energy; blue-green = narrated minerals; blue = hydration; white/blue-white = neural signalling; red-gold = muscle activity. Use only when relevant and never as decoration.


DIRECT-VIDEO PROMPTS: Produce N standalone unnumbered lines in map order. ONE-TO-ONE COUNT: N scene-map lines = N direct-video lines = N on-screen-text lines = N sound-design lines. Position i in every section must represent the same exact spoken words and atomic visual beat.
